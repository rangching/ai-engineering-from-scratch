# zh-TW 翻譯術語表

課程翻譯成台灣繁體中文時遵守的規則。專業詞彙保留英文，一般敘述用台灣慣用語。

## 保持英文（不翻）

- 程式碼、指令、檔名、路徑、URL、連結目標、metadata 的 key（`**Type:**`、`**Time:**` 等）
- 技術名詞：backpropagation、gradient、tensor、embedding、attention、transformer、tokenizer、fine-tuning、agent、MCP、prompt、token、GPU、CUDA、API、virtual environment、package manager、runtime
- 產品、函式庫、論文名稱：PyTorch、NumPy、uv、pnpm、Rust、Julia

## 固定譯法

| English | zh-TW |
|---------|-------|
| lesson | 課程 |
| phase | 階段 (phase) |
| Build It / Use It / Ship It | 動手做 (Build It) / 實際使用 (Use It) / 交付 (Ship It) |
| Learning Objectives | 學習目標 (Learning Objectives) |
| The Problem / The Concept | 問題 (The Problem) / 核心概念 (The Concept) |
| Exercises / Hints | 練習 (Exercises) / 提示 (Hints) |
| software / data / program | 軟體 / 資料 / 程式 |
| information / network | 資訊 / 網路 |
| verify / install / configure | 驗證 / 安裝 / 設定 |

## 用語原則

- 使用台灣用語：軟體、程式、資料、品質、預設，不用「软件」「信息」「默认」。
- 中英文之間加半形空格，標點用全形（，。：；）。
- 句子短而直接，語氣像朋友聊天。
